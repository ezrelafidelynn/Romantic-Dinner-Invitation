# Romantic Dinner Invitation 💕

A beautiful, interactive React app to ask your boyfriend to dinner on November 15th, 2025!
Here's the demo version : [for-my-orbit.vercel.app](https://for-my-orbit.vercel.app)

## Features ✨

- 🌹 Romantic and cute design with soft colors
- 💕 Floating heart animations in the background
- 📅 Special date highlighting (November 15th, 2025)
- 🎵 Interactive invitation with response options
- 💖 Celebration animation when they say yes
- 📱 Mobile-responsive design
- ✨ Beautiful typography with Dancing Script and Poppins fonts

## How to Run 🚀

1. **Install dependencies:**

   ```powershell
   cd romantic-dinner-invitation
   npm install
   ```

2. **Start the development server:**

   ```powershell
   npm start
   ```

3. **Open your browser:**
   The app will automatically open at `http://localhost:3000`

## Customization Ideas 💡

- Change the date in `src/App.js` if needed
- Modify the "Your Loving Partner" signature at the bottom
- Add your own romantic message in the invitation text
- Customize colors in the CSS file to match your preferences

## What It Does 💖

This romantic invitation app:

- Displays a beautiful card asking for a dinner date
- Shows floating hearts in the background
- Includes dinner details like time (7:00 PM) and atmosphere
- Has interactive "Yes" and "Maybe" buttons
- Shows a celebration when they say yes
- Gives a sweet response if they need to think about it

Perfect for surprising your boyfriend with a cute, tech-savvy dinner invitation! 🥰
